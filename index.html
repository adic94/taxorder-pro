Jak korzystać z TaxOrder Pro?
1. Przejdź do Pojazdy → zaznacz checkboxem pojazdy do deklaracji → ustaw liczbę osi i zawieszenie dla każdego.
2. Przejdź do Kalkulator → uzupełnij dane podatnika → sprawdź wyliczone kwoty.
3. Kliknij DT-1 / DT-1/A → wydrukuj gotowe formularze lub eksportuj do Przyjaznych Deklaracji.
4. Ważne: dla przyczep i naczep wpisz DMC zespołu pojazdów (przyczepa + ciągnik) — inaczej kategoria nie zostanie przypisana.

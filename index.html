📋 Ścieżka 2 — Wniosek przez ePUAP (pełny dostęp do danych pojazdów)

        

          Dla firm chcących sprawdzać konkretne pojazdy (np. weryfikacja DMC, daty rejestracji, właściciela) wymagany jest formalny wniosek:
        

        

          Zaloguj się na ePUAP z kwalifikowanym podpisem elektronicznym lub podpisem zaufanym
        

        

          Wypełnij wniosek: Usługa CEP: Przyjmowanie wniosków o udostępnienie danych
        

        

          W rubryce nr 4 wpisz dokładny cel — "weryfikacja danych pojazdów własnej floty dla celów podatkowych (DT-1)"
        

        

          Wniosek rozpatrywany w ciągu 14–30 dni
        

        

          Po akceptacji otrzymasz klucz API z dostępem do pełnych danych pojazdu po nr rej.
        

      

    

    

      ⚠ Ważne: Publiczne API CEPiK (api.cepik.gov.pl) używa whitelist IP — dostęp z przeglądarki internetowej jest możliwy wyłącznie przez serwer pośredniczący lub po wpisaniu IP Twojego serwera na listę dozwolonych. Program obsługuje oba scenariusze.
